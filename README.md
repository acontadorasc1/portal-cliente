# Portal do Cliente — A Contadora

Site onde os clientes enviam dados e documentos para processos societários
(abertura, alteração, baixa, abertura e extinção de filial).

- O site é só a página: **nenhum dado de cliente fica guardado aqui**.
- Os envios vão direto para o Google Drive do escritório, na pasta
  "Portal do Cliente - Envios", pelo recebedor em `google-apps-script/recebedor.gs`
  (que roda na conta Google do escritório).
- Pode ser instalado na tela inicial do celular (ícone A Contadora).
